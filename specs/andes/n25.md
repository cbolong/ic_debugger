## mvendorid
- Offset: 0x000
- Reset: -
- Verified: RISC-V 特權架構規格 v1.11（ratified） §3.1.2 Figure「Vendor ID register (mvendorid)」
- Description: 供應商識別碼（CSR 0xF11）— JEDEC 製造商編號；官方允許回傳 0 表示未實作或非商用實作

| Bits  | Field | Access | Reset | Description |
|-------|-------|--------|-------|-------------|
| 31:7 | Bank | RO | - | JEDEC 連續碼（0x7f）的個數 |
| 6:0 | Offset | RO | - | JEDEC ID 的最後一個位元組（去掉同位元） |

## marchid
- Offset: 0x004
- Reset: -
- Verified: RISC-V 特權架構規格 v1.11（ratified） §3.1.3「Machine Architecture ID Register」
- Description: 微架構識別碼（CSR 0xF12）— 唯讀；官方允許回傳 0 表示未實作。開放源碼實作為開放編號、商用實作最高位元為 1

| Bits  | Field | Access | Reset | Description |
|-------|-------|--------|-------|-------------|
| 31:0 | ArchID | RO | - | 微架構 ID（實際值需查原廠文件） |

## mimpid
- Offset: 0x008
- Reset: -
- Verified: RISC-V 特權架構規格 v1.11（ratified） §3.1.4「Machine Implementation ID Register」
- Description: 實作版本識別碼（CSR 0xF13）— 唯讀，內容由供應商定義；官方允許回傳 0 表示未實作

| Bits  | Field | Access | Reset | Description |
|-------|-------|--------|-------|-------------|
| 31:0 | ImpID | RO | - | 實作版本（編碼方式由供應商定義） |

## mhartid
- Offset: 0x00C
- Reset: -
- Verified: RISC-V 特權架構規格 v1.11（ratified） §3.1.5「Hart ID Register」
- Description: Hart（硬體執行緒）編號（CSR 0xF14）— 唯讀；官方要求系統中必須有一個 hart 的 mhartid 為 0

| Bits  | Field | Access | Reset | Description |
|-------|-------|--------|-------|-------------|
| 31:0 | HartID | RO | - | 本 hart 的整數編號（同一系統內唯一） |

| 21 | TW | RW | - | Timeout Wait：低特權模式執行 WFI 逾時觸發例外 |

| 2 | WPRI | WPRI | - | 保留（官方圖示為 WPRI） |

### Enum: FS
- 0b00: Off（存取浮點狀態會觸發非法指令例外）
- 0b01: Initial
- 0b10: Clean
- 0b11: Dirty

### Enum: XS
- 0b00: All off
- 0b01: None dirty or clean, some on
- 0b10: None dirty, some clean
- 0b11: Some dirty

### Enum: MPP
- 0b00: 使用者模式（U）
- 0b01: 監督者模式（S）
- 0b11: 機器模式（M）

### Enum: SPP
- 0: 進入陷阱前為使用者模式（U）
- 1: 進入陷阱前為監督者模式（S）

### Enum: MIE
- 0: 機器模式中斷全域關閉
- 1: 機器模式中斷全域開啟

### Enum: SIE
- 0: 監督者模式中斷全域關閉
- 1: 監督者模式中斷全域開啟

### Enum: MPRV
- 0: 以目前特權等級進行位址轉換與保護檢查
- 1: 載入／儲存改以 MPP 的特權等級進行

## mtvec
- Offset: 0x018
- Reset: -
- Verified: RISC-V 特權架構規格 v1.11（ratified） §3.1.7 Figure「Machine trap-vector base-address register (mtvec)」＋ Table「Encoding of mtvec MODE field」
- Description: 陷阱向量基底位址與模式（CSR 0x305）— 官方要求必須實作，但可以是唯讀的硬接值

| Bits  | Field | Access | Reset | Description |
|-------|-------|--------|-------|-------------|
| 31:2 | BASE | WARL | - | 向量表基底位址的 [31:2]（必須 4-byte 對齊；Vectored 模式另有對齊要求） |
| 1:0 | MODE | WARL | - | 向量模式 |

### Enum: MODE
- 0b00: Direct — 所有陷阱都跳到 BASE
- 0b01: Vectored — 非同步中斷跳到 BASE + 4 × cause，同步例外仍跳 BASE
- 0b10: 保留（官方：≥2 為 Reserved）
- 0b11: 保留（官方：≥2 為 Reserved）

## mcause
- Offset: 0x02C
- Reset: -
- Verified: RISC-V 特權架構規格 v1.11（ratified） §3.1.16 Figure「Machine Cause register (mcause)」＋ Table「Machine cause register (mcause) values after trap」＋ §3.3 Reset
- Description: 陷阱原因（CSR 0x342）— 先看 Interrupt 判斷是中斷還是例外，再看 Code。官方：重置後的 mcause 值由實作定義（不區分重置原因者應為 0）

| Bits  | Field | Access | Reset | Description |
|-------|-------|--------|-------|-------------|
| 31 | Interrupt | RW | - | 陷阱類型（1 = 中斷） |
| 30:0 | Code | WLRL | - | 原因編號（同一編號在中斷與例外下意義不同，見下方對照）。例外：16–23／32–47 保留給未來標準用途，24–31／48–63 保留給自訂用途；中斷：12–15 保留、≥16 保留給平台使用 |

### Enum: Interrupt

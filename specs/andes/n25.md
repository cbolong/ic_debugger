## mvendorid
- Offset: 0x000
- Reset: -
- Description: 供應商識別碼（CSR 0xF11；JEDEC 編碼，Andes 為 0x31E）

| Bits | Field  | Access | Reset | Description |
|------|--------|--------|-------|-------------|
| 31:7 | Bank   | RO     | -     | JEDEC 連續碼（bank）數 |
| 6:0  | Offset | RO     | -     | JEDEC ID（bank 內編號） |

## marchid
- Offset: 0x004
- Reset: -
- Description: 微架構識別碼（CSR 0xF12；Andes 各核心不同，可用來確認 dump 來源是不是這顆 CPU）

| Bits | Field  | Access | Reset | Description |
|------|--------|--------|-------|-------------|
| 31:0 | ArchID | RO     | -     | 微架構 ID |

| 23    | X     | RO     | -     | 非標準擴充（Andes 自訂指令） |
| 22:21 | RES0  | RO     | 0     | 擴充字母 W／V（本核心未實作，讀為 0） |

| 19    | RES0  | RO     | 0     | 擴充字母 T（本核心未實作，讀為 0） |
| 18    | S     | RO     | -     | 監督者模式 |

| 12    | M     | RO     | -     | 整數乘除法 |
| 11:9  | RES0  | RO     | 0     | 擴充字母 L／K／J（本核心未實作，讀為 0） |

### Enum: S

### Enum: M

### Enum: A

## mtvec
- Offset: 0x018
- Reset: -
- Description: 陷阱向量基底位址與模式（CSR 0x305）

| Bits | Field | Access | Reset | Description |
|------|-------|--------|-------|-------------|
| 31:2 | BASE  | RW     | -     | 向量表基底位址（欄位值 = 位址右移 2 位） |

### Enum: MODE
- 0b00: Direct — 所有陷阱都跳到 BASE
- 0b01: Vectored — 中斷跳到 BASE + 4 × cause
